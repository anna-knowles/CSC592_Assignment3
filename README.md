CSC 461/592 - Assignment 3 VR Assembly

Team: Anna Knowles


VR Assembly

The assembly object is a bird house consisting of 15 pieces to reconstruct. In the further part of the scene, 
the user will be able to view a larger rendering of the bird house for more visual instruction, but the program 
walks through which pieces should be placed step by step. While the instructions are displayed in front of the viewer, 
the position the puzzle piece should be in is also highlighted. Once finished, the instructions display "Birdhouse Completed!"
and fireworks are displayed.
